Backup

A complete copy of everything in the hub as one file. Keep it somewhere safe. Restoring replaces what is in the hub with what is in the file. Slip photos stay in the hub and are not inside the file.

Set up the Apps Script once

  1. Open or create a Google Sheet for your finances.
  2. Go to Extensions, then Apps Script. Delete what is in Code.gs and paste the script below. Save.
  3. Reload the sheet. A Finance Hub menu appears next to Help.
  4. Here, tap Copy data for Sheets. In the sheet, choose Finance Hub, then Import data, paste and press Import.

The script writes whatever tables the hub sends, so new features show up as new tabs without changing it. The first import asks Google for permission to edit the sheet.
